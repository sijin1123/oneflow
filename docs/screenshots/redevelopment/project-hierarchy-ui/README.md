# UI-276 Project Hierarchy Composition

This folder records the UI-276 visual verification for the functional project
Hierarchy surface.

- `desktop.png`: compact frame navigation, URL-backed search/filter/sort,
  expanded hierarchy rows, real work-item properties, and item actions.
- `mobile.png`: three hierarchy levels with status, priority, assignee, and the
  touch-visible item menu contained at `390x844`.
- `loading-mobile.png`: hierarchy-shaped loading rows that retain the final
  mobile geometry without document overflow.

The surface is independently implemented with OneFlow routes, APIs, tokens,
Lucide icons, and existing work-item hierarchy/action contracts. No Plane
source, package, asset, CSS, DOM hierarchy, exact visual tokens, wording, or
branding was copied.
